# 招银数智创新 Meetup 杭州站 - 让 NPU 更易共享：HAMi vNPU 技术演进与招商银行落地实践

**Date:** July 25, 2026
**Event:** 招银数智创新 Meetup 杭州站 (CMB Digital Innovation Meetup, Hangzhou)
**Speaker:** 王纪飞 / Jifei Wang - Dynamia R&D Engineer & HAMi Approver

## Topic

企业 AI 基础设施的重点，正从“拥有算力”转向“用好算力”。本次分享介绍 HAMi vNPU 从规格固定的**硬切分**向按需灵活分配的**软切分**演进，让切分后的 NPU 在 Kubernetes 中被统一发现、调度和治理；并结合招商银行生产落地，说明双方围绕国产化环境适配、NPU 资源切分与超节点任务调度的协作实践。

生产验证关键指标：

- 超节点硬件入池率 **100%**
- 跨机调度概率降低 **30%**
- 资源切分粒度达 **1 GB 显存** 与 **1% 算力**
